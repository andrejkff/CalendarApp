# CalendarApp

React Native calendar application using Firebase Authentication and Firestore.

## Requirements

- Node.js >= 22.11.0
- Android Studio + Android SDK (Android)
- Xcode + CocoaPods (iOS)

## Installation

git clone https://github.com/andrejkff/CalendarApp.git
cd CalendarApp
npm install

## Android

npm run android

## iOS

not tested yet

## Tests

npm test
